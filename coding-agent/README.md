# Coding Agent MCP Integration

Connect your AI coding assistant (e.g. Claude Code) to LGND's code assistant, which provides knowledge about the Embeddings API.

## Setup

1. Copy the MCP config to your project root:

```bash
cp .mcp.example.json /path/to/your/project/.mcp.json
```

2. Set your API key and launch:

```bash
export LGND_API_KEY=sk_...
claude
```

The Code Assistant MCP provides your agent with detailed knowledge of the API endpoints and can help with questions about leveraging the Embeddings API for your project.
