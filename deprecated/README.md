# Deprecated

This folder contains previously supported features that are no longer maintained or supported by LGND.

## Overview

The resources in this directory represent older functionality, integrations, or configurations that have been phased out. While the code and documentation remain available for reference, we do not provide support or updates for these features.

## Contents

- **coding-agent** - Legacy MCP (Model Context Protocol) integration for coding assistants. This integration is no longer actively maintained.

## Migration & Alternatives

If you were using any of these deprecated features, we recommend:

1. **Check the main documentation** - Newer, supported features may provide similar or improved functionality
2. **Review breaking changes** - See the `breaking-changes/` directory for details on what changed
3. **Contact support** - For questions about migrating away from deprecated features, reach out to the LGND team
